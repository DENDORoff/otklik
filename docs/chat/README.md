# Архив чата

Здесь хранится полная история рабочей сессии, в которой создавался «Отклик».

| Файл | Что внутри |
|---|---|
| `../../ИСТОРИЯ-ЧАТА.md` | Читаемая стенограмма: все реплики пользователя и ассистента, вызовы инструментов в свёрнутом виде, конспекты контекста |
| `2026-11-11-session.jsonl` | Машиночитаемый архив: по одному JSON на сообщение, полные входы и выходы инструментов, без reasoning-блоков |
| `export-chat.js` | Скрипт экспорта из локальной базы OpenCode |

## Чем отличается от других документов

- **`ИСТОРИЯ-РАБОТЫ.md`** — аналитический итог: решения, этапы, баги, проверки.
  Читать первым, если нужен смысл.
- **`ИСТОРИЯ-ЧАТА.md`** — дословная стенограмма: кто что сказал и какие команды
  выполнялись. Читать, если нужны детали, формулировки или точная
  последовательность действий.
- **`AGENTS.md`** — краткая инструкция для следующего ИИ-агента.

## Как обновить

Нужен Node.js 22.5+ (встроенный `node:sqlite`). Скрипт только читает базу
OpenCode и ничего в ней не меняет.

```powershell
cd D:\DW\hackathon
node docs/chat/export-chat.js
```

По умолчанию берётся последняя сессия из
`%USERPROFILE%\.local\share\opencode\opencode.db`. Путь можно переопределить:

```powershell
$env:CHAT_DB = "D:\path\to\opencode.db"
node docs/chat/export-chat.js
```

## Приватность

Перед записью скрипт:

- заменяет домашние пути на `%USERPROFILE%`;
- вырезает коды устройства GitHub и токены вида `gho_…`, `ghp_…`;
- не включает reasoning-блоки модели и служебные инструкции окружения.

Архив опубликован в публичном репозитории. Перед обновлением стоит просмотреть
diff: в переписке могут появиться новые персональные данные.

## Актуальность

Экспорт — снимок на момент запуска. Сообщения, появившиеся после, в файлы
не попадают; для актуализации достаточно повторить команду выше.
