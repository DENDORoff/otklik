# «Отклик» — система обратной связи и предложений сотрудников

Работающий MVP для хакатона ГК «Модус Трейд». Сотрудник подаёт проблему или идею,
система маршрутизирует обращение в профильный отдел, начальник назначает исполнителя,
автор видит итог и оценивает результат.

**Публичный репозиторий:** https://github.com/DENDORoff/otklik
**Код и инструкция по запуску:** [`otklik/README.md`](otklik/README.md)

> Название «Сигнал» не используется по условиям хакатона. Рабочее имя — **«Отклик»**.

## Быстрый старт

```powershell
cd D:\DW\hackathon\otklik
Copy-Item .env.example .env
npm install
npm run setup
npm run dev
```

Демо-пароль всех аккаунтов — `demo1234`; на `/login` есть кнопки быстрого входа.
Основные роли: `purchase@otklik.local` (сотрудник), `head.it@otklik.local` (начальник
отдела), `admin@otklik.local` (администратор).

## Что реализовано

- Три роли, серверная проверка прав, JWT-сессия в httpOnly-cookie, bcrypt.
- Мастер создания из 3 шагов: тип и категория, описание с поиском похожих, срок и отправка.
- «Другое» со своей формулировкой → очередь «Неназначенные» у администратора.
- Маршрутизация «категория → отдел» из БД, SLA 3/7/14 дней, подсветка просрочки.
- Полный жизненный цикл, уточнения, отказ, перенаправление (лимит 3), дубликаты.
- Список с вкладками «Все / Мои / На мне / Просроченные», фильтры, CSV-выгрузка.
- Аналитика, обезличенная лента улучшений, настройки уведомлений.
- Админка: правила маршрутизации, очередь, запросы по персональным данным, журнал безопасности.
- Юридический контур: политики, согласие, cookie-баннер, форма запроса на удаление данных.
- SEO: SSR, metadata/OG, `sitemap.xml`, `robots.txt`; доступность и мобильная вёрстка без
  горизонтального скролла.
