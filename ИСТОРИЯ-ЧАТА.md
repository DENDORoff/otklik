## Рекомендация: Next.js + TypeScript + Prisma + SQLite

Почему именно это под наш кейс (10 экранов CRUD, роли, статусная машина, аналитика, демо на Windows):

- **Один язык и один процесс.** Страницы + Server Actions вместо отдельного REST-бэкенда — меньше кода и меньше рассинхрона между фронтом и API.
- **Tailwind** — точнее всего повторяет брендбук modus-trade (наши `#ED1111`, `#082742`, радиус 4px, uppercase Gilroy). Готовые UI-киты (MUI/AntD) пришлось бы переопределять.
- **Prisma + SQLite** — файл БД, ноль настройки, сид из датасета одним скриптом; переход на PostgreSQL = смена строки подключения.
- **Auth.js (Credentials + bcrypt)** — 3 роли в сессии + middleware для прав.
- **Recharts** — графики для аналитики; **Zod** — валидация форм; **exceljs** — выгрузка отчётов (в ТЗ есть).
- **Деплой демо**: локально `npm run build && npm start` или Vercel. Docker не нужен.

Чего сознательно избегаем: отдельный GraphQL/REST-слой, микросервисы, Redux, тяжёлые UI-киты — всё это съедает время хакатона без выигрыша.
