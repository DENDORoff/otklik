# AGENTS.md — точка входа для ИИ-агентов

Этот файл — краткий «handoff» для любого ИИ-агента, который продолжает работу над проектом.
Полная хронология сессии и все решения — в [`ИСТОРИЯ-РАБОТЫ.md`](ИСТОРИЯ-РАБОТЫ.md).

## Что это за проект

Работающий MVP **«Отклик»** — система обратной связи и предложений сотрудников
для хакатона ГК «Модус Трейд».
Сквозной процесс: подача → маршрутизация по категории → начальник отдела → исполнитель →
итог → оценка автора → закрытие. Роли: сотрудник, начальник отдела, администратор.

> Название «Сигнал» использовать **запрещено** условиями хакатона. Рабочее имя — **«Отклик»**.

## Стек и почему

| Слой | Технология | Причина |
|---|---|---|
| Фреймворк | Next.js 15 (App Router), React 19 | SSR + Server Actions без отдельного REST-слоя |
| Язык | TypeScript 6 | TS 7 несовместим с Next 15 — **не обновлять** |
| Стили | Tailwind 3 | быстрый брендированный UI |
| БД | SQLite + Prisma 6 | нулевая настройка на демо-машине |
| Авторизация | JWT (`jose`) в httpOnly-cookie + `bcryptjs` | без внешних сервисов |
| Валидация | zod | проверка форм на сервере |

## Доменные правила (не ломать)

- **Маршрутизация** — правило «категория → отдел» в БД. Нет правила → очередь
  «Неназначенные» + уведомление администратору. «Не направлять» деактивирует правило.
- **Категория «Другое»** — без правила маршрутизации; автор вводит свою формулировку,
  она хранится в `Appeal.customCategory`, обращение уходит админу на маршрутизацию.
- **Исполнителя назначает начальник отдела** (ТЗ п. 2.2), не автор.
- **SLA**: высокий — 3 дня, средний — 7, низкий — 14. Просрочка подсвечивается.
- **Жизненный цикл**: Новое → На рассмотрении → (Ожидает уточнения ↔ На рассмотрении) →
  В работе → Реализовано → Закрыто; также Отклонено и Дубликат.
- **Лимит перенаправлений** — 3, далее эскалация администратору.
- **Оценка автора 1–5** закрывает обращение и попадает в аналитику.
- **Видимость**: автор — свои; начальник — свой отдел + личные; админ — все.
  Чужое обращение по прямой ссылке → 404 (брендированная русская страница).
- Все проверки прав — **на сервере** в Server Actions, не только в UI.
- **Необратимые действия** (отказ, дубликат, оценка) подтверждаются модалкой
  `ConfirmSubmit`; остальные — `SubmitButton` с pending-состоянием.
- **Персональные данные**: согласие фиксируется в `User.consentVersion/consentAt`,
  запросы на доступ/удаление — `/data-request`, обработка — в админке.
- **Тема оформления**: светлая, тёмная и «как в системе» — переключается в разделе
  «Настройки» (`src/components/appearance.tsx`). Тема — класс `.dark` на `<html>`,
  палитра — CSS-переменные в `globals.css` (`:root` / `.dark`). Выбор в `localStorage["theme"]`
  и в cookie `theme`; приоритет у сохранённого выбора над системной настройкой.
- **Язык интерфейса**: RU (по умолчанию) / EN / KZ, переключается в разделе «Настройки».
  Ключ перевода — исходная русская строка,
  словари в `src/lib/i18n/{en,kz}.ts`. Сервер: `await getTranslator()` из `@/lib/i18n/server`,
  клиент: `useT()` из `@/components/i18n-provider`. Новые строки оборачивать в `t("...")`
  и сразу добавлять в оба словаря; клиентские строки — в `src/lib/i18n/client-keys.ts`.

## Известные ограничения

- Уведомления только внутрисистемные (email имитируется).
- Справочники (отделы, люди, категории) меняются через сид; визуальный конструктор — этап 2.
- Интеграции Битрикс24 / 1С — только описаны, не реализованы.
- Данные **только синтетические** из датасета; реальные сведения компании использовать нельзя.
- Резервный скринкаст демо не записан.

## Правила для агента

1. Не переименовывать продукт и не использовать «Сигнал».
2. Не коммитить `.env`, `dev.db`, `node_modules`, `.next`, `storage/uploads`.
3. Не обновлять TypeScript до 7 и не убирать alias `@` из `next.config.mjs`.
4. Сохранять бренд: `#082742`, `#ED1111`, шрифт Montserrat (SIL OFL, self-host), интерфейс на русском.
   Для тёмной темы палитру менять только через токены `globals.css`, а не «в обход» них.
5. После изменений: `npm.cmd run build`, затем прогон затронутого сценария и `npm.cmd run db:reset`.
6. Обновлять `ИСТОРИЯ-РАБОТЫ.md` при значимых изменениях — это журнал для следующих агентов.
7. Стенограмма чата в проекте не хранится (удалена 12.11.2026): в репозитории только
   аналитический журнал `ИСТОРИЯ-РАБОТЫ.md` и этот файл.
